# 시작 전 확인사항

Claude가 일반 지식으로 정리한 항목이다. 법·세무·수수료는 바뀔 수 있으므로 **공식 출처나 담당 기관에서 확인한 뒤** 상태를 바꾼다.

## 회사 관련
| 항목 | 상태 | 메모 |
|---|---|---|
| 겸업 허용 여부 (취업규칙) | 사용자 인사팀 확인 중 | |
| 사업자등록 가능 여부 (A 방식이면 필요) | 인사팀 질문에 포함 권장 | |
| 경업 범위 (식품·건강 카테고리 제한 여부) | 인사팀 질문에 포함 권장 | 건기식은 이미 제외 |
| 회사 PC·회사 계정 사용 | 확인 필요 | 지금 쓰는 Claude 계정이 회사 도메인 계정이다. 부업 작업을 회사 계정·장비로 해도 되는지 함께 물어보고, 안 되면 개인 계정으로 옮긴다 |

## 판매 준비 (A 방식 기준)
| 항목 | 상태 | 메모 |
|---|---|---|
| 사업자등록 (간이/일반 과세) | 확인 필요 | 미가공 농수산물은 부가세 면세 품목이다 → 면세사업자 여부도 확인 |
| 통신판매업 신고 | 확인 필요 | 면제 기준이 있으므로 최신 기준 확인 |
| 스마트스토어 판매자 유형 (개인 → 사업자 전환) | 확인 필요 | |
| 원산지 표시 | 필수 | 온라인 판매도 원산지 표시 의무가 있다 |
| 식품 관련 영업신고 | 확인 필요 | 미가공 농수산물만 팔면 대상이 아닐 가능성이 높고, 가공·소분하면 대상일 수 있다 → 관할 시·군·구 |
| 스마트스토어 수수료 최신표 | 확인 필요 | 개편 이력 있음 |

## 생산자 계약 (A·B 공통)
- 공급가와 택배비 포함 여부
- 발송 마감 시간과 발송 소요일
- 배송 사고(파손·부패) 시 재발송·환불 책임과 비용 부담
- 1차 CS 담당 (생산자가 맡는 조건 권장)
- 사진·영상 소재 제공 범위와 사용 권한
- 정산 주기와 방식
- B 방식이면: 수수료율, 성과 측정 기준, 스토어·광고 계정 권한 범위, 계약 종료 조건

## 광고 측정 (본업 경험상 미리 짚을 것)
- 스마트스토어에는 META 픽셀을 자유롭게 설치할 수 없어서, META 광고 성과를 META 대시보드만으로 판단하기 어렵다. 유입 경로 파라미터와 스마트스토어 통계를 함께 봐야 한다(설정 방법 확인 필요).
- 첫 시즌 주력 광고는 **네이버 검색광고·쇼핑검색광고**가 현실적이다. 구매 의도가 있는 검색 수요를 바로 받기 때문이다. META는 선물세트처럼 콘텐츠로 설득할 상품에 보조로 붙인다.
- 광고 계정은 개인 명의로 새로 만든다. 회사 BM·회사 광고 계정과 섞지 않는다.
