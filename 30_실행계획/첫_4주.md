# 첫 4주 계획 (2026-11-16 ~ 12-13)

목표: **2027년 설 선물 시즌에 상품 1~2개로 판매를 시작할 준비를 끝낸다.** 목표 수익은 상품이 정해진 뒤 허용 CPA와 예상 판매량으로 다시 잡는다.

시간 예산: 평일 2시간 × 5일 + 주말 4시간 × 2일 = 주 최대 18시간. 무리 없이 **주 14시간**을 기준으로 잡는다.

## 1주차 (11/16~11/22) — 방향 정하기
- [ ] 인사팀 답변 받기 → [[40_확인사항/체크리스트]] 갱신
- [ ] A(내 스토어) / B(생산자 스토어 대행) 방식 결정
- [ ] 설 선물 후보 10개 뽑고 네이버 데이터랩·키워드 도구로 검색량과 시즌 곡선 확인
- [ ] 후보별 쇼핑 검색 상위 판매자 5곳씩 보기 (가격대, 구성, 리뷰 수, 상세페이지 수준)

## 2주차 (11/23~11/29) — 후보 좁히기
- [ ] [[20_상품소싱/상품선정_기준]] 점수표로 후보 3개로 축소
- [ ] 후보별 허용 CPA 계산 (공급가는 시장가로 추정)
- [ ] 생산자 찾는 경로 정리, 접촉할 생산자 3~5곳 목록 (이름 대신 코드로 기록)
- [ ] 생산자 제안 문구 초안 (A용·B용 따로)

## 3주차 (11/30~12/6) — 생산자 확보
- [ ] 생산자 접촉 (사용자 직접)
- [ ] 공급가·발송·CS·정산 조건 협의 → 체크리스트의 계약 항목 기준
- [ ] A 방식이면 사업자·통신판매업 신고 절차 확인 후 진행 (사용자 직접)

## 4주차 (12/7~12/13) — 판매 준비
- [ ] 상품 구성 확정 (선물세트 규격, 가격)
- [ ] 상세페이지 구조와 카피 초안
- [ ] 광고 계획: 검색 키워드 목록, 일 예산, 허용 CPA 기준의 중단 조건
- [ ] 1월 초 판매 시작 일정 확정
