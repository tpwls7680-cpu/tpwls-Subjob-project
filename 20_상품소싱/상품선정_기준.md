# 상품 선정 기준과 시즌 캘린더

## 선정 기준 (점수표)
후보마다 항목별로 1~5점을 매기고, 합계가 높은 순으로 좁힌다.

| 항목 | 보는 것 | 왜 중요한가 |
|---|---|---|
| 검색 수요 | 네이버 데이터랩·검색광고 키워드 도구의 월 검색량과 시즌 곡선 | 수요가 없으면 광고비로 수요를 만들어야 한다 |
| 마진 | 허용 CPA 1만원 이상 나오는가 ([[10_사업모델/위탁판매_구조]] 계산식) | 광고를 쓸 여유가 있는가 |
| 객단가 | 3만원 이상 구성 가능한가 | 택배비·수수료를 흡수하는가 |
| 배송 안정성 | 파손·부패 위험, 산지 발송 속도 | CS 시간을 결정한다 |
| 생산자 역량 | 당일 발송, 사진 제공, 연락 응답 속도 | 위탁판매 성패의 절반 |
| 스토리 | 산지·재배 방식·생산자 이야기 | 대형 판매자와 가격 말고 다른 걸로 싸울 수 있는가 |
| 재구매 | 시즌 내 재주문, 다음 해 재구매 | 고객 1명당 가치 |
| 경쟁 강도 | 쇼핑 검색 상위가 대형 판매자·농협 위주인가 | 들어갈 틈이 있는가 |

**제외 기준**
- 건강기능식품 또는 기능성을 내세워야 팔리는 상품 → 본업과 겹치고 표시·광고 규제도 무겁다.
- 가공식품(즙·잼·절임·건조 가공 등)은 식품 관련 영업신고가 필요할 수 있다 → 첫 시즌은 **미가공 농수산물**을 우선한다(확인 필요).

## 시즌 캘린더 (대략, 산지·품종별로 다르므로 확인 필요)
| 시기 | 후보 |
|---|---|
| 11~12월 | 감귤, 곶감·홍시, 과메기, 굴, 대방어, 김장 재료(막바지) |
| 1~2월 | **설 선물세트**(사과·배·한라봉·천혜향·곶감·김·멸치), 딸기 |
| 3~4월 | 딸기, 봄나물, 주꾸미, 도다리 |
| 5~6월 | 참외, 햇마늘·햇양파, 매실, 블루베리 |
| 7~8월 | 옥수수, 복숭아, 감자, 수박 |
| 9~10월 | **추석 선물세트**, 사과·배, 햇밤, 고구마, 대하, 전어 |
| 연중 | 김, 멸치, 쌀 (가공·소분 여부에 따라 신고 확인) |

## 지금 시점(11월 중순)에 맞는 첫 타깃
- **2027년 설(2월 초)** 선물 수요가 가장 가깝고 큰 시즌이다. 선물 주문은 설 2~3주 전에 몰리므로, 1월 초에 판매를 시작하려면 **12월 안에 생산자와 상품 구성을 확정**해야 한다.
- 선물세트는 객단가가 높아 허용 CPA가 넉넉하고, 첫 테스트에 유리하다.
- 감귤은 지금 바로 팔 수 있는 상품이라 시장 감을 익히는 소규모 테스트로 쓸 수 있다. 다만 경쟁이 매우 치열하다.

## 생산자를 찾는 경로
1. 지인·고향 네트워크 (신뢰가 가장 빠르다)
2. 이미 스마트스토어를 하지만 리뷰·상세페이지가 약한 생산자 → B 방식 제안에 적합
3. 지역 농업기술센터, 로컬푸드·작목반, 지역 농협
4. 도매 플랫폼은 차별점이 약하므로 후순위
